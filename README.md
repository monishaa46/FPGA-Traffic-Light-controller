# FPGA-Based Traffic Light Controller with Priority System

## Project Overview
This project implements a Traffic Light Controller using Verilog HDL. The controller manages traffic signals for two roads and provides an emergency vehicle priority feature.

## Features
- Two-road traffic light management
- Green, Yellow, and Red signal states
- Emergency vehicle priority override
- Finite State Machine (FSM) implementation
- Simulation using EDA Playground/Vivado

## Tools Used
- Verilog HDL
- EDA Playground
- EPWave Simulator

## Simulation Result
The waveform verifies correct traffic signal transitions and emergency priority operation.
